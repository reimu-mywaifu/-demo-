# [沐光小食](https://reimu-mywaifu.github.io/-demo-/) (Muguang Snacks) 官方網站

這是一個為「沐光小食」設計的靜態官方網站，採用現代簡約與莫蘭迪色系風格打造。

## 專案特色

- **純靜態網頁**：採用純 HTML、CSS 與 Vanilla JS 開發，無須經過任何複雜的打包或編譯流程（如 Webpack 或 Vite），載入速度極快。
- **防止搜尋引擎索引**：已在所有頁面加入 `<meta name="robots" content="noindex, nofollow">` 標籤，確保網站部署後不會出現在 Google 等搜尋引擎的搜尋結果中。
- **響應式設計**：支援手機與桌機版面，包含流暢的行動版漢堡選單。
- **GitHub Pages 友善**：檔案結構完全吻合 GitHub Pages 預設環境，不會有路由轉址 (404) 的問題。

---

## 如何更新內容並上傳到 GitHub

當您修改了網站內容（例如更新了 `menu.html` 裡的菜色，或是修改了 `css/style.css` 裡的顏色）之後，請依照以下 3 個簡單的步驟，將最新的進度推播 (Push) 到 GitHub：

### 步驟 1：加入所有變更
在您的終端機（Terminal）或命令提示字元中，確認目前路徑在專案資料夾底下 (`c:\Users\User\Desktop\fooddemo`)，然後輸入以下指令：

```bash
git add .
```
這會告訴 Git：「把這個資料夾底下所有修改過、新增的檔案，全部準備好要進行版本紀錄」。

### 步驟 2：提交版本紀錄
接著輸入以下指令，並寫下您這次做了什麼修改（引號內的文字可以自由更改）：

```bash
git commit -m "更新菜單內容"
```
這會在您的電腦本地端建立一個正式的版本紀錄。

### 步驟 3：推播到 GitHub
最後，把本地端的紀錄推播到 GitHub 伺服器上：

```bash
git push
```
執行成功後，GitHub 上的檔案就會更新，如果您有開啟 GitHub Pages，稍等幾分鐘後，線上的網站也會自動更新為最新版本！

> **提示**：以上三個步驟是您未來每次修改完網頁後，都固定會用到的一套「存檔並上傳」流程。
